CÁCH CHẠY
1. Double-click index.html.
2. Không cần Node.js, npm hay server.

ĐIỀU HƯỚNG
- Bấm Home / Profile / Research / Projects / Achievements / Publications / Contact.
- Có thể dùng phím mũi tên trái/phải để chuyển mục.
- Trên điện thoại bấm biểu tượng menu góc phải.

THAY VIDEO PROJECT
Mỗi project có 1 folder riêng trong:
assets/projects/

Ví dụ:
assets/projects/04-omni-trajectory-tracking/demo.mp4

Chỉ cần thay demo.mp4 bằng video thật và giữ nguyên tên file.
cover.jpg là ảnh dự phòng nếu video không tải được.
